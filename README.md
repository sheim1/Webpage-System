Student Management System

A simple web application that manages student data using PHP and MySQL.

Project Description

This project allows users to add student names and ages, save the data in a MySQL database, and display the stored data in a table.

Features

Add student name and age.
Store data in MySQL database.
Display students in a table.
Toggle student status between 0 and 1.

Technologies Used

HTML
CSS
JavaScript
PHP
MySQL
